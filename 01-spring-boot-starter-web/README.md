# spring-boot-starter-web

A Python implementation of the web layer provided by the Spring Boot starter `spring-boot-starter-web`. This module delivers a REST API server using FastAPI, Uvicorn, and Pydantic as the equivalents of Tomcat, Spring MVC, and Jackson.

## Overview

In Spring Boot, `spring-boot-starter-web` gives an application three core capabilities:

| Spring Boot Component | Purpose | Python Equivalent |
|---|---|---|
| Tomcat | Embedded web server | Uvicorn |
| Spring MVC | Request routing | FastAPI routes |
| Jackson | Object and JSON conversion | Pydantic |

This module reproduces those capabilities and adds the protective layers that a production web service requires.

## Features

- Full CRUD API for the `Account` resource with JSON request and response bodies.
- Automatic type coercion and validation for path and query parameters.
- Request body validation with field constraints and unknown field rejection.
- Content type enforcement returning 415 for non-JSON requests on JSON endpoints.
- Request body size limit returning 413 for oversized payloads.
- Global exception handler that returns a safe 500 response without leaking stack traces.
- CORS configuration restricted to trusted origins.
- Pagination support with `skip` and `limit` query parameters.
- Thread-safe in-memory store that survives concurrent requests.

## Requirements

- Python 3.12 or newer
- pip

## Installation

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

## Running the Server

```bash
uvicorn main:app --reload
```

The server starts at `http://127.0.0.1:8000`. The interactive API documentation is available at `http://127.0.0.1:8000/docs`.

## API Endpoints

| Method | Path | Description |
|---|---|---|
| GET | `/accounts` | Lists accounts with pagination |
| GET | `/accounts/export` | Returns export metadata |
| POST | `/accounts` | Creates a new account |
| GET | `/accounts/{id}` | Returns a single account |
| PUT | `/accounts/{id}` | Updates an account |
| DELETE | `/accounts/{id}` | Deletes an account |

### Account model

| Field | Type | Constraints |
|---|---|---|
| id | integer | Generated by the server |
| name | string | 1 to 100 characters |
| balance | float | Zero or greater |

### Pagination

The `GET /accounts` endpoint accepts the following query parameters:

| Parameter | Default | Constraint |
|---|---|---|
| skip | 0 | Greater than or equal to 0 |
| limit | 100 | Between 1 and 100 |

## Testing

```bash
pytest -v
```

The test suite focuses on non-happy-path scenarios. It verifies that the service returns the correct status codes and does not crash when it receives invalid, missing, oversized, or malicious input. Covered scenarios include wrong path parameter types, missing records, wrong HTTP methods, empty bodies, malformed JSON, unknown fields, oversized bodies, concurrent requests, wrong content types, and special characters in URLs.
